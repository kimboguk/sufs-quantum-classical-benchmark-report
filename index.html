🔴 Classical 최적화의 문제점

  • 국소 최적해에 갇힘: CVXPY ECOS/SCS solver가 채권을 충분히 활용하지 못하는 차선책 포트폴리오로 수렴
  • 초기값 의존성: Equal weight(1/N)에서 시작하여 제한된 해공간만 탐색
  • Gradient 기반의 한계: Convex optimization은 한 방향으로만 수렴하여 더 나은 조합을 놓침
  • 과도한 집중: 평균 3.4개 자산만 선택하여 분산 효과 제한

🟢 Quantum Annealing의 강점

  • 글로벌 탐색 능력: 3000 스텝 × 40 입자로 광범위한 해공간을 체계적으로 탐색
  • 국소해 탈출 메커니즘: Simulated Annealing의 확률적 특성으로 나쁜 해를 일시적으로 수용하며 탈출
  • 다양한 자산 조합 발견: 채권 + 주식 + 섹터 ETF의 최적 조합을 자동 발견
  • 적절한 분산: 평균 4.8개 자산 선택으로 리스크 분산과 집중의 균형
  • 메타휴리스틱 우위: Non-convex 복잡한 포트폴리오 최적화 문제에서 더 효과적

📚 원인: Overfitting vs Generalization

  • 훈련 데이터: 매우 우수 ✅

3000×40 = 120,000회 평가로 과거 패턴을 너무 세밀하게 학습 → 미래 일반화 성능 저하

📈 Classical Max Sharpe
  • 훈련 데이터: 보통 ⚠️
  • 테스트 성과: 우수 ✅
  • 장점: 일반화 (Generalization)

단순한 Convex 최적화로 보수적 접근 → 미래 예측력 우수

💡 왜 이런 결과가 나왔는가?

  • 복잡한 모델의 함정: Quantum의 광범위한 탐색이 오히려 훈련 데이터의 노이즈까지 학습
  • 단순 모델의 강건성: Classical의 제약적 접근이 본질적 패턴만 포착하여 미래에 더 잘 작동
  • Bias-Variance Tradeoff: 복잡도 ↑ → 훈련 오차 ↓ but 일반화 오차 ↑
  • 샘플 외 성능: 과거 4년 데이터로 학습 → 미래 1년은 "본 적 없는" 데이터

🔧 개선 방향

이는 현재 구현의 한계이며, 다음과 같은 개선이 필요합니다:

1️⃣ 수익/리스크 모델링 개선

  • 단순 과거 수익률 대신 더 정교한 예측 모델 사용
  • 시변 변동성(Time-varying volatility) 모델 도입
  • 팩터 모델(Fama-French 등) 적용
  • 거시경제 변수 반영

2️⃣ 과적합 방지 메커니즘

  • Regularization: L1/L2 penalty 추가로 복잡도 제어
  • Cross-validation: K-fold 검증으로 일반화 성능 평가
  • Early stopping: 검증 성과 기반 최적화 중단
  • Ensemble: Quantum + Classical 조합

3️⃣ 학습 방법론 개선

  • Rolling window 대신 Expanding window 고려
  • Walk-forward optimization 적용
  • Out-of-sample 검증 기간 확대
  • 하이퍼파라미터 튜닝 (입자 수, 스텝 수)

🎓 연구의 의의

이러한 "모순적으로 보이는" 결과는 실제로는 매우 중요한 발견입니다:

  • 알고리즘 능력 입증: Quantum이 훈련 데이터에서 더 나은 최적해를 찾는 것은 분명함
  • 실무 적용 시사점: 단순히 "높은 ex-ante Sharpe"만으로는 부족하며, 일반화 성능이 핵심
  • 향후 연구 방향: 양자 최적화 + 정규화 기법 결합이 최선의 접근
  • 현실적 평가: 과적합 문제는 모든 최적화 기법의 공통 과제이며, 이를 인지하고 개선하는 것이 중요

📊 결론: Ex-ante 우위 + Ex-post 개선 = 최적의 접근

현재 결과는 Quantum Annealing이 더 나은 최적화 알고리즘임을 입증하는 동시에, 실전 적용을 위해서는 과적합 방지 메커니즘이 필수임을 보여줍니다. 수익/리스크 모델과 학습 방법을 개선하면, Quantum의 글로벌 탐색 능력과 우수한 일반화 성능을 동시에 달성할 수 있을 것으로 기대됩니다.

⚠️ Classical 최적화의 한계

Classical Max Sharpe 최적화가 낮은 성과를 보인 이유는 국소 최적해(Local Optima) 문제 때문입니다:

  • CVXPY의 Convex solver(ECOS/SCS)가 제한된 해공간만 탐색
  • 초기값(equal weight)에서 시작하여 가까운 국소해로 수렴
  • 채권을 충분히 활용하지 못하는 차선책 포트폴리오 생성
  • Gradient 기반 최적화의 근본적 한계

✨ Quantum Annealing의 실용적 가치

본 연구는 양자 최적화의 실제 금융 응용 가능성을 입증합니다:
